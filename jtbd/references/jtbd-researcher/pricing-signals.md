# Pricing Signals Research Guide

## Search Patterns

```
"[product category] pricing"
"[product name] price"
"how much does [product category] cost"
"[product category] free vs paid"
"[product category] worth it"
```

## What to Extract

- **Price range**: free tier / entry / mid / premium (in USD/month)
- **Pricing model**: per seat / flat / usage-based / freemium / one-time
- **Premium drivers**: what features are gated behind higher tiers?
- **WTP signals**: what do users say about price vs value? ("worth it", "too expensive", "no-brainer")

## Output Format

```
Price range: $0 (free) → $X/mo (entry) → $Y/mo (pro)
Model: [freemium / per-seat / flat / usage]
Premium drivers: [feature 1], [feature 2], [feature 3]
WTP signal: "[quote about value perception]"
```
