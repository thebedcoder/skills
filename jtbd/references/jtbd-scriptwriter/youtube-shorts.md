# YouTube Shorts Script Guide

**Length:** 30–60s | **Hook window:** 3–5s | **Tone:** Structured, can build slower | **Sound:** Mostly on

## Script Format

```
━━━ YOUTUBE SHORTS SCRIPT ━━━
Target: [Persona + job]
Angle: [Which of the 3 angles]
Searchable title concept: [What someone would type to find this]
Length: [30s / 45s / 60s]

[0–4s]   HOOK
"[Bold opening claim or pattern interrupt]"
VISUAL: [High-contrast opener — face or bold text]

[4–12s]  PROBLEM EXPANSION
"[Describe the struggling moment — slightly more detail than TikTok]"
VISUAL: [Problem illustrated]

[12–35s] SOLUTION + DEMO
"[Walk through the job being done — outcome visible]"
VISUAL: [Screen recording or product demo if applicable]

[35–50s] PROOF
"[Number / testimonial / result]"
VISUAL: [Stat card or social proof screen]

[50–60s] CTA
"[Single action + what they'll get]"
VISUAL: [End card with link or subscribe prompt]

TITLE: [Searchable, outcome-led, under 60 chars]
DESCRIPTION: [2–3 sentences, keyword-rich, includes link]
```

## Shorts-Specific Rules
- YouTube audience has slightly higher patience — 3–5s hook window
- Searchability matters: title keywords help Shorts surface in search + recommendations
- Screen recordings and demos perform well — Shorts viewers expect more substance
- End screen / subscribe prompt is worth including — YouTube rewards subscriber growth
- VO quality matters more here than on TikTok — consider cleaner audio
