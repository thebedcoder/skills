# Jobs to Be Done — Megaskill
## Product Brief → Research → Personas → Competitors → Landing Page → Ad Scripts

Current date: !`date +"%B %d, %Y"`

## Invocation

If `$ARGUMENTS` contains a MODE number (e.g. "MODE 3"), jump directly to that mode — run required-inputs check first.
If `$ARGUMENTS` contains a product brief, start with MODE 0. Checkpoint after each mode before continuing.
If `$ARGUMENTS` is empty, print the MODE GUIDE and ask which mode to run.

### Chain Checkpoints (mandatory after every mode)

After each mode, show:

```
━━━ CHECKPOINT ━━━
MODE [N] complete.
💾 Export? [Y] Save to jtbd-[product-slug]-mode[N]-[YYYY-MM-DD].md  [N] Chat only
Continue to MODE [N+1] — [Name]? What you'll get: [one-line]
```

Default: export + proceed. Silence/"yes"/"continue" = export and go.

### Export Protocol

Filename: `jtbd-[product-slug]-mode[N]-[YYYY-MM-DD].md` (slug = lowercase, spaces → hyphens).
Contents: `# JTBD [Mode Name] — [Product Name]` · Date · Confidence (High/Medium/Low) · Inputs · full output · `Generated by jobs-to-be-done-megaskill`.
Write to working directory.

### Conversational Routing

If user describes their situation without invoking a mode explicitly:
- Product idea / brief → suggest MODE 0
- Has reviews, transcripts, tickets → suggest MODE 1
- Has research output, needs personas → suggest MODE 2
- Has job + persona, needs positioning → suggest MODE 2B
- Ready to write copy → suggest MODE 3
- Needs ad scripts → suggest MODE 4

Always confirm before proceeding.

## MODE GUIDE

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  WHAT DO YOU HAVE?                        → START HERE                      │
├─────────────────────────────────────────────────────────────────────────────┤
│  Only a product idea or one-liner brief   → MODE 0  Synthetic Research      │
│  Real interviews, transcripts, reviews    → MODE 1  Discovery & Analysis    │
│  JTBD research (from Mode 0 or 1)         → MODE 2  Persona Definition      │
│  A focus job + primary persona            → MODE 2B Competitor Analysis     │
│  Focus job + persona + competitive gap    → MODE 3  Landing Page Copy       │
│  Focus job + persona + outcome to lead    → MODE 4  Ad Scripts              │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **MODE 0** — Spawns 🔍 RESEARCHER for real market data, then synthesizes job performers, four forces, opportunity scores, interview guide. → [commands/mode-0-research.md](commands/mode-0-research.md)
- **MODE 1** — Spawns parallel 🧪 ANALYST agents per qualitative source. → [commands/mode-1-discovery.md](commands/mode-1-discovery.md)
- **MODE 2** — Builds 2–3 situation-based personas ranked by commercial value. → [commands/mode-2-personas.md](commands/mode-2-personas.md)
- **MODE 2B** — Spawns 4 parallel 🕵️ SCOUT agents (one per competitor tier), builds differentiation matrix + positioning. → [commands/mode-2b-competitors.md](commands/mode-2b-competitors.md)
- **MODE 3** — Spawns 7 parallel ✍️ COPYWRITER agents (one per page section), assembles + consistency-checks. → [commands/mode-3-landing-page.md](commands/mode-3-landing-page.md)
- **MODE 4** — Spawns parallel 🎬 SCRIPTWRITER agents (one per platform), 3 angles each. → [commands/mode-4-ad-scripts.md](commands/mode-4-ad-scripts.md)

## The Four Forces (reference for all modes)

**Push** (frustration with current) · **Pull** (excitement toward outcome) · **Habit** (inertia) · **Anxiety** (switching fear)

Progress = Push + Pull > Habit + Anxiety

Job types: **Functional** (the task) · **Emotional** (how to feel) · **Social** (how to be seen)
