# FAQ Section Guide

## JTBD Mapping
Each Q&A → one Anxiety from persona's four forces

## Rules
- One entry per anxiety identified in research
- Q = the anxiety phrased as a genuine customer question (not a marketing question)
- A = direct answer + one de-risking mechanism
- 4–6 entries minimum, never more than 8
- Order: most common anxiety first

## De-risking Mechanisms
- Free trial / money-back guarantee
- "Takes X minutes to set up"
- Specific number ("We support X integrations")
- Named case study ("Teams at [type of company] use this for...")
- Comparison ("Unlike [alternative], you don't need to...")

## FAQ Format
```
Q: [Anxiety phrased as a genuine question]
A: [Direct answer]. [De-risking mechanism].
```

## Question Types by Anxiety
- Switching cost: "How long does it take to get started?"
- Learning curve: "Do I need to know [X] to use this?"
- Commitment: "Can I cancel anytime?" / "Is there a free trial?"
- Trust: "Is my data secure?" / "Who else uses this?"
- Fit: "Is this for [my specific situation]?"

## Anti-patterns
- ❌ "What is [Product]?" (belongs in hero, not FAQ)
- ❌ Questions no one actually asks ("Can I use this on mobile?")
- ❌ Answers that re-pitch features instead of defusing anxiety
