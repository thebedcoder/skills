# Instagram Reel Script Guide

**Length:** 15–30s | **Hook window:** 3s | **Tone:** Slightly polished | **Sound:** Design sound-off first

## Script Format

```
━━━ INSTAGRAM REEL SCRIPT ━━━
Target: [Persona + job]
Angle: [Which of the 3 angles]
Sound-off strategy: [How message lands with no audio]
Length: [15s / 30s]

[0–3s]   HOOK
VISUAL:       [Strong opener — high contrast, face, motion, or bold text card]
TEXT OVERLAY: "[Struggling moment or bold claim — large, readable]"
AUDIO:        "[Trending sound or natural VO]"

[3–8s]   PROBLEM
VISUAL:       [Relatable problem scene]
TEXT OVERLAY: "[Pain point in customer language]"
AUDIO:        "[VO describing the frustration]"

[8–18s]  SOLUTION
VISUAL:       [Product solving the problem — clean, clear]
TEXT OVERLAY: "[Outcome achieved]"
AUDIO:        "[Outcome-first explanation]"

[18–25s] PROOF + CTA
VISUAL:       [Result screen + CTA graphic]
TEXT OVERLAY: "[Proof stat or quote] + [CTA action]"
AUDIO:        "[Proof claim + instruction]"

CAPTION: [2–3 sentences, conversational, ends with soft CTA]
HASHTAGS: [5–8]
```

## Reel-Specific Rules
- Sound-off is the default on Instagram feed — every frame must carry the message via text overlay
- Hook at 3s (vs 2s on TikTok) — slightly more patience from audience
- Aesthetic matters more than TikTok — clean cuts, readable fonts, consistent visual style
- Trending audio helps discoverability even if VO carries the message
- Save link for bio or Stories — no clickable links in Reel captions
