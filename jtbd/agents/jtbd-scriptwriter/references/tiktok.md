# TikTok Script Guide

**Length:** 15–30s | **Hook window:** 2s | **Tone:** Raw, high energy | **Sound:** Design for both on/off

## Script Format

```
━━━ TIKTOK SCRIPT ━━━
Target: [Persona + job]
Hook type: [Pain / Outcome / Proof / Pattern Interrupt / Identity]
Angle: [Which of the 3 angles]
Length: [15s / 30s]

[0–2s]   HOOK
AUDIO:        "[Opening line — fast, high energy, specific]"
TEXT OVERLAY: "[Same or amplified — bold, large font, max 5 words]"
VISUAL:       [Scene — what's on screen]

[2–8s]   PROBLEM
AUDIO:        "[Their exact frustration in their words]"
TEXT OVERLAY: "[Key frustration — 3–6 words max]"
VISUAL:       [Relatable scene of the problem]

[8–20s]  SOLUTION
AUDIO:        "[Product name + what it does for the job]"
TEXT OVERLAY: "[Outcome statement]"
VISUAL:       [Product in use — outcome visible]

[20–25s] PROOF
AUDIO:        "[Social signal: number / quote / result]"
TEXT OVERLAY: "[Proof stat or quote fragment]"

[25–30s] CTA
AUDIO:        "[Single action — link in bio / try free]"
TEXT OVERLAY: "[CTA — bold, urgent, outcome-framed]"
VISUAL:       [Logo + CTA screen]

CAPTION: [3–4 sentences, keyword-rich, conversational]
HASHTAGS: [5–8 — mix niche + broad]
```

## TikTok-Specific Rules
- First 2 seconds: pattern interrupt or it's over — no slow builds
- Text overlay must work standalone (sound-off is common on FYP)
- Native feel > polished production — shaky cam, talking head, screen recording all work
- Hook must be the FIRST thing on screen — no logos, no intros
- CTA: "Link in bio" or "Comment [word] for the link" — direct URL doesn't work in captions
