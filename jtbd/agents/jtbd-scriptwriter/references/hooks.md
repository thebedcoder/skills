# Hook Formulas Reference

Hook is most important 2–3 seconds. Doesn't stop scroll → nothing else matters.

Forces referenced below defined in [SKILL.md → #forces](../../../skills/jtbd/SKILL.md#forces). Cite — don't redefine.

## Hook Types

### PAIN (`Push force`-first)
Best for cold traffic. Makes them feel seen before showing the solution.
```
"If you've ever [frustrating experience], this is for you."
"[Pain point stated as accusation]"
"Why does [category] still work like [broken analogy]?"
"Nobody talks about [uncomfortable truth in your category]."
```

### OUTCOME (`Pull force`-first)
Best for warm traffic who knows the category.
```
"I went from [before state] to [after state] in [timeframe]."
"Before: [pain]. After: [outcome]. Here's what changed."
"[Desired outcome] — here's exactly how."
```

### PROOF (Trust-first)
Best for retargeting or low-trust categories.
```
"[Number] people switched from [competitor] last month. Here's why."
"[Customer type] are using [Product] to [outcome]. This is why."
"We helped [N] [job performers] [outcome] — here's the method."
```

### PATTERN INTERRUPT
Breaks the scroll with something unexpected.
```
"[Competitor name] will never show you this."
"Stop using [common workaround] for [job]. Seriously."
"The [category] industry doesn't want you to know this."
```

### IDENTITY
Calls out the exact person watching.
```
"This is specifically for [job performer] who [struggling moment]."
"If you're a [persona type], you need to watch this."
```

## Hook Writing Rules
- TikTok: under 3 words OR a complete sentence — nothing in between
- Hook must work as text overlay with audio off
- First word matters most — start with the pain, the number, or the name
- Never start with "Hey guys" or "So I wanted to share"
