# Adjacent Tools Research Guide

Adjacent tools: different product category, but hired for the same underlying job.

Forces referenced below defined in [SKILL.md → #forces](../../../skills/jtbd/SKILL.md#forces). Cite — don't redefine.

## Search Patterns
```
"how do people [accomplish the job] without [product category]"
"[job outcome] using [adjacent tool like Notion/Slack/Sheets]"
"[job outcome] hack"
```

## What Makes a Tool "Adjacent"

The customer is not in your category but is getting a version of the same job done. Examples:
- A project manager using Notion for a job a dedicated PM tool would do
- A founder using a spreadsheet for a job a CRM would do
- A team using Slack threads for a job an async video tool would do

## Analysis
Same format as direct — but focus on:
- **Why they chose adjacent over dedicated**: usually price, familiarity, or integration
- **The compromise they're making**: what the adjacent tool can't do that a dedicated tool would
- **The trigger to switch**: when does the adjacent tool break down enough that they seek a dedicated solution?
