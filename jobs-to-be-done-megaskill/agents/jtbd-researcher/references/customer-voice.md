# Customer Voice Research Guide

## Search Patterns

```
"[product name] reviews"
"[product category] reddit"
"r/[relevant subreddit] [product category]"
"[product name] site:reddit.com"
"[product category] problems frustrations"
```

## What Counts as Customer Voice

Extract only quotes that reveal:
- A **struggling moment**: specific situation where the person felt friction
- A **desired outcome**: what success looks like to them
- A **frustration** with current alternatives
- A **switching trigger**: what made them look for something else

## Format

```
• [Source: Reddit/AppStore/G2/etc] | "[exact or close-paraphrase quote]"
  → JTBD signal: [struggling moment / desired outcome / frustration / switching trigger]
```

## Quality Filter

- Prefer: emotional, specific, first-person, past-tense accounts
- Skip: generic praise ("great app!"), feature requests framed as specs
- Mark uncertainty: if paraphrasing, write "(paraphrased)"

## Minimum Target

5–8 quotes with clear JTBD signal
