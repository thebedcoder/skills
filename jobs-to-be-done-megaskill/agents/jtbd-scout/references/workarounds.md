# Analog Workarounds Research Guide

Workarounds: no dedicated software, pure DIY — spreadsheets, manual processes, pen and paper, asking a colleague.

## Search Patterns
```
"[job outcome] without software"
"DIY [job outcome]"
"[job outcome] template"
"[job outcome] manually"
"free way to [job outcome]"
```

## Why Workarounds Matter

Workarounds reveal the **Habit force** at its strongest. People who use them:
- Have already decided dedicated software isn't worth the cost/effort
- Have a known, predictable process (even if painful)
- Will only switch when the cost of the workaround becomes intolerable

## Analysis

For each workaround:
1. **What it is**: spreadsheet / email thread / Notion template / manual tracking / etc.
2. **Why it sticks**: what keeps people using it (free, familiar, already have it, flexible)
3. **What it costs them**: the real price of using a workaround (time, errors, scale limits)
4. **Breaking point**: the volume or complexity threshold where it collapses
