# Direct Competitor Research Guide

Direct competitors: same category, same job, similar target persona.

## Search Patterns
```
"[product category] alternatives"
"best [product category]"
"[product name] vs [competitor]"
"[product category] comparison"
```

## Analysis Per Competitor

For each competitor, answer:
1. **Job it does well** — where does it genuinely succeed?
2. **Job it fails** — what's the gap users complain about?
3. **Force it creates** — does its failure create Push (active frustration) or Habit (inertia)?
4. **Best for** — which type of user, which situation, does it serve best?
5. **Firing trigger** — what specific event makes a user fire it and search for alternatives?
